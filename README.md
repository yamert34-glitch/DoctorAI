# Doctor AI

Doctor AI is our NASA HUNCH student engineering project. We are developing an offline-first medical assistance prototype, and this repository is where I host a website that introduces the project and explains what we are building.

## Project website

Visit the website: [Doctor AI](https://yamert34-glitch.github.io/DoctorAI/)

The site covers the project's purpose, how the prototype works, and the engineering behind it. The website is made with HTML, CSS, and JavaScript.

## This repository

- `website/` contains the website files.
- `.github/workflows/pages.yml` publishes the site to GitHub Pages when website files are updated on `main`.

This repository is for the project website. The Doctor AI prototype's source code and project materials are maintained separately.

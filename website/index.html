01 THE PROJECT

When communication is limited,
preparation matters.

Long-distance missions can include communication delays and times without contact. Doctor AI explores a practical question: how might a crew member collect and organize health information onboard while waiting to connect with mission control?

Our prototype combines a guided check-in with local software and reference information. It is a student engineering project, not a replacement for professional medical care.

02 HOW IT WORKS

A check-in, step
by step.

The application guides the user through health information and brings it together for review. Some features depend on the build and installed tools.

  1. 01

    Choose a profile

    Start a local profile or select an existing one. Face matching is an experimental profile-selection option.

  2. 02

    Answer guided questions

    Share symptoms, when they began, relevant history, medications, and other requested details.

  3. 03

    Organize information locally

    Protocol checks and local reference lookup organize the information. An optional local language model can draft additional text.

  4. 04

    Review and save

    Read the on-screen response, then save assessment details to the selected local profile.

Like other AI tools, generated responses can sometimes be wrong or incomplete and should be reviewed carefully.

04 ENGINEERING & TECHNOLOGY

Built with tools
we can learn from.

We are building and testing a modular C++ application, with optional interface, language-model, and hardware experiments.

C++17 + CMakeMain application, assessment flow, and build configuration.CORE
llama.cpp + ggmlOptional local inference with compatible GGUF models.OPTIONAL
Qt 6 WidgetsTouchscreen interface in configured builds.OPTIONAL
OpenCVFace detection and template matching for profile selection.EXPERIMENTAL
OpenSSL + JSONEncrypted assessment payloads and structured local data.LOCAL DATA
ESP32-S3Separate pulse-sensor firmware experiment.EXPERIMENTAL

Built and tested on regular computers. Raspberry Pi/Linux is a target environment; current software has not been tested on spacecraft hardware.
